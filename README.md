# 签到助手

在自己的电脑上给国服米游社做每日签到。页面用 Vue，签到由本机服务完成。浏览器关掉以后，只要这个服务还开着，到点仍会签到。

目前支持崩坏：星穹铁道。一个米游社账号下绑定的多个角色会分开显示，也可以记下多个米游社账号。

## 环境

- Node.js 20 或更高版本
- 能访问米哈游接口的网络

## 安装

```bash
git clone https://github.com/UR0609/starrail-checkin.git
cd starrail-checkin
npm install
```

## 启动

开发时开页面和服务：

```bash
npm run dev
```

打开 http://127.0.0.1:5173 。页面先要求输入本机访问账号。用户名和密码写在运行这台电脑的 `data/本地记录.md`，这个文件不会进入 Git 仓库。登录后可以点「修改密码」，需要填写当前密码。新密码至少 8 个字符。

要一直挂着自动签到，先构建再只开服务：

```bash
npm start
```

然后打开 http://127.0.0.1:8787 。

服务器上用 Docker 跑时，登录数据放在项目里的 `data` 目录，并挂进容器。更新镜像或重建容器时不要删除这个目录。具体更新命令写在服务器维护记录里。

服务只监听本机 `127.0.0.1`，同一台电脑上的浏览器才能打开。

## 添加账号

点「添加角色」，用下面任意一种方式登录。两种方式记下的是同一个米游社账号，之后不用每天再登。

扫码：

1. 打开手机米游社，进入「我的」，点右上角扫一扫。
2. 扫描页面上的二维码，并在手机上确认登录。

手机验证码：

1. 填写绑定米游社的 11 位手机号，点「获取验证码」。
2. 如果出现安全验证，在页面上自己完成。
3. 把短信验证码填进去，点「登录」。

再点一次「添加角色」，可以继续添加别的账号。

登录凭证写在本机的 `data/accounts.json`。这个文件已经在 `.gitignore` 里，上传 GitHub 时不会带上。不要把该文件、Cookie 或验证码发到仓库、截图或别人的电脑上。

## 每天签到

默认每天 10:00（北京时间）给已开启的账号和角色签到。时间可以在页面上改，改完要点「保存时间」。

每个角色可以单独关闭「参与签到」。整个账号也可以关闭「每天自动签到」。

「立即签到」只签当前账号。「全部签到」签所有已开启的账号。「刷新状态」向米哈游查询今天是否已经签过。

如果 10 点时服务没开，下次启动后会补签当天还没签的账号。电脑关机或服务停掉时，到点不会签。

## 签到日历

每个角色卡片下面有一个月历。金色日期是已经签过的日子。点中间的年月可以直接跳到某年某月，也可以用「上个月」「下个月」翻页。

如果这个月没有漏签，日历会按米哈游的记录补全本月已签的日期。漏过的日子，只会标出这个页面实际看到的日期。

## 登录失效

扫一次通常能用比较久。短期凭证过期后，程序会用保存的长期凭证自动换一套再签。

下面这些情况需要重新登录：放得太久、在手机米游社里退出登录、改了密码，或被米哈游作废。失效后，账号卡片上会提示重新登录。

扫码如果出现「当前设备或网络环境存在风险」，改用手机验证码登录。

米哈游如果在签到时要求验证码，当天请打开米游社手动签一次。接口变更后签到可能失败，页面上会留下米哈游返回的原因。

## 上传到 GitHub 之前

确认仓库里没有 `data/`、`node_modules/` 和 `client/dist/`。这三项已写入 `.gitignore`。

```bash
git status
```

列表里不应出现 `accounts.json`。如果出现了，不要提交它。
